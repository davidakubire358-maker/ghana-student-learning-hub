# Ghana Student Learning Hub

A free, mobile-friendly starter learning website for Ghanaian JHS (BECE) and SHS (WASSCE) students.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a web browser.
3. No installation, account, server, or paid subscription is required.

## Included
- Mathematics, English Language and Integrated Science
- JHS and SHS level selection
- Starter lessons with examples
- Multiple-choice quizzes with instant feedback and explanations
- Study tips
- Progress dashboard saved in the browser on the device

## Publish it free
You can publish the folder using GitHub Pages or Netlify's free static-site hosting. Upload the extracted folder (with `index.html` at its root) and follow the host's publish instructions.

## Important
This is a starter learning resource, not an official GES or WAEC product. Check topics and requirements against the current syllabus and your teachers' guidance. Progress is stored locally in the browser and does not sync between devices.
